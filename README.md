# Bài thực hành HTML Form

Repository gồm hai biểu mẫu:

1. `hobby-form.html`: Form đăng ký sở thích.
2. `student-registration.html`: Form đăng ký học viên.

Trang `index.html` cung cấp liên kết đến hai form.

## Kiểm tra thuộc tính name

- Form sở thích: `yourname`, `email`, `hobby`.
- Form học viên: `fullname`, `email`, `phone`, `birthday`, `gender`, `address`, `course`, `study_type`, `hobby`, `note`.

Các radio button trong cùng nhóm có cùng `name`. Các checkbox sở thích dùng chung `name="hobby"`.

Ảnh chụp kết quả nằm trong thư mục `screenshots`.
